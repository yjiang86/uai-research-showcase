# Included and excluded material

## Included

- A closed set of original memory-runtime modules, relocated as one portable package.
- Selected existing synthetic behavioral assertions, with their original bodies.
- Four existing synthetic mechanism fixtures and a small executable wrapper.
- Architecture, contribution, research-boundary and usage documentation.
- A public upstream attribution/license notice for the referenced competition formulation.
- Actual local validation status; no fabricated example outputs.

## Excluded

- Original Git history, remote configuration, operating instructions and host registries.
- Private subject or experiment data, benchmark datasets, personal records and raw biological results.
- Credentials, account/session state, internal hosts, absolute paths and infrastructure topology.
- Chat transcripts, owner communications, private reviews, recovery journals and raw execution logs.
- Model weights, binaries, external services, training/HPC scripts and hardware implementations.
- Unreviewed working-tree changes and unrelated research components.

All demonstration records are synthetic. Referenced external projects are
attributed; their repositories and datasets are not bundled. Private operating
and source-provenance evidence is kept outside this delivery repository.

The CoreV2Memory sealed-application facade is not exported with this minimal
subset: its benchmark/provider-dispatch imports are outside the selected
dependency closure. The original application demo recommendation is retained
as internal design evidence, not shipped as a non-working portable example.
Only the approved public UAI_1 prose is copied from the specialist factcheck;
its internal evidence archive is not included.
